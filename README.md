# Martial-Law-Support-in-South-Korea
Replication materials for "Delegating Democracy Away?: Martial Law Support in South Korea"

This folder contains all of the files needed to replicate the empirical results and create the figures in “Delegating away Democracy?: Martial Law Support in South Korea.” by Brandon B. Park and Yuko Sato, Political Research Quarterly. 

If you have questions, please contact ysato@ku.edu.tr

The folder contains the following files:

- 01 descriptıve_statistics.do: Stata do file containing the commands needed to replicate the descriptive statistics.
- 02 main_analysis.do: Stata do file containing the commands needed to replicate the empirical models and substantive effects in the manuscript.
- 03 appendix.do: Stata do file containing the commands needed to replicate the empirical models and substantive effects in the Appendix.
- 250104_final.dta: corresponding dataset required that contains the variables required for the empirical models, descriptive statistics, and substantive effects in the manuscript and Appendix.
